# Movie Drawer (무비서랍)

영화 제목을 검색하고 포스터, 평점, 줄거리, 장르, 개봉일을 확인하는 프런트엔드 프로젝트입니다. HTML, CSS, JavaScript로 구성되어 있습니다.

## 샘플 모드

1. 저장소를 내려받고 `Movie-Drawer.html`을 브라우저에서 엽니다.
2. TMDB 토큰 입력란을 비워 두고 **기생충** 또는 **Interstellar**를 검색합니다.
3. 영화 카드를 선택해 상세 정보를 확인합니다. **닫기** 또는 **Esc**로 결과 목록에 돌아갈 수 있습니다.

설치나 빌드 없이 샘플 영화 3편을 탐색할 수 있습니다.

## TMDB 실시간 검색

1. [TMDB API 설정](https://www.themoviedb.org/settings/api)에서 **API Read Access Token**을 확인합니다.
2. Movie Drawer의 **TMDB 실시간 검색 설정**을 펼치고 토큰을 입력합니다.
3. 영화 제목을 검색하고 결과 카드를 선택합니다. 요청이 실패하면 화면의 **다시 시도** 버튼을 사용합니다.

토큰은 파일이나 브라우저 저장소에 기록되지 않습니다. 브라우저가 TMDB에 직접 요청하므로 개발자 도구에서 요청 헤더를 볼 수 있습니다. 공유할 HTML과 Git 커밋에는 실제 토큰을 넣지 마세요.

## 브라우저 점검

- **키보드**로 검색창에 이동해 Enter로 검색합니다. Tab으로 결과 카드에 이동해 Enter로 상세 화면을 열고 Esc로 닫습니다. 선택했던 카드에 포커스가 돌아오는지 확인합니다.
- **화면 너비**를 데스크톱과 모바일 크기로 바꿔 검색창, 영화 카드, 상세 창에 가로 스크롤이 생기는지 확인합니다.
- **실시간 모드**에서 한국어 검색 결과와 상세 정보가 표시되는지 확인합니다.

영화 데이터와 포스터는 [TMDB](https://www.themoviedb.org/)에서 제공받습니다.

This product uses the TMDB API but is not endorsed or certified by TMDB.
